# 分析通过后自动公开

使用者确认取消内部隔离，且覆盖此前 UNKNOWN 自动放行约定：预筛 UNKNOWN 与 BLOCK 默认都是不通过。随后确认增加专用人工预筛审核例外，详见 [人工预筛设计](2026-11-06-manual-prefilter-pass-design.md)：原始 UNKNOWN 保留，当前版本经有理由的人工审核后继续通用模型分析，不允许公开范围、索引或普通字段修正代替审核。

## 实施

1. 预筛保留原始标签；UNKNOWN 停止后续评分、分类和写作，归一化为 block。所有公开出口继续使用统一发布层，要求当前版本存在成功的通过分析，未分析、失败、被拦截和人工下架保持不可见。
2. 删除内部隔离参与方式、目录采集限制和后台文案。保留 editorial 与 hot_signal；公开不等于精选，精选仍需评分与归组。全文许可开关不变，教程默认只展示摘要和原文链接。
3. 新迁移增加仅允许两种参与方式的 NOT VALID 约束，并删除历史约束。独立修复脚本先预览、逐来源转换和审计、处理历史 UNKNOWN，再逐条重建发布投影，最后验证约束；不删除原始材料、模型输出或回执，不重新调用模型。
4. 验证 UNKNOWN 阻断、历史 UNKNOWN 不泄漏、当前通过分析自动公开、过期/失败分析不公开、人工下架不恢复，以及目录采集和所有公开出口。

不新增开关、环境变量或付费请求，不执行 Git 提交。

## 人工修正反馈故障

2026-11-06 使用者报告公开范围、标记收录和人工修正提示成功但不生效。本机只读审计核验发现，SenseNova 与“AI帮你剪视频”等条目确实保存了公开意图、分类或精选意图，原始预筛却为 UNKNOWN，实际投影保持 withdrawn、eligible=false、indexable=false。这不是写入失败，也不是缓存问题；后台只检查 HTTP 成功，未区分设置已保存与发布条件已满足。

修复保持原发布规则：公开范围修改和索引许可核对事务内实际结果，不能生效就返回带说明的冲突并回滚；新提交的强制精选必须已有公开且合格的精选候选，归组未完成时只保存候选意图，不能声称已经入选。普通内容字段仍可在未公开时校正，前端依据返回的有效范围与精选结果提示，避免“已重新发布”的误报。既有隐而未生效的人工意图与历史审计不删除，模型输出、回执、UNKNOWN／BLOCK 与人工下架边界不变。

在现有 `tests/admin-corrections.test.ts` 复现旧版 UNKNOWN 请求返回 200 与无摘要索引未拒绝，修复后覆盖 API 冲突原因、事务完整回滚、普通修正仍可保存、无摘要／下架不能索引及候选等待归组；现有发布测试继续保证拦截标签不能人工绕过。

旧强制精选意图没有改动时，表单不重复提交该字段，保留历史设置而不让它妨碍普通标题修正。现有 `apps/web/tests/cache.test.ts` 增加真实生产网页与内存假 API 的交互回归，验证失败对话框保持打开、显示 UNKNOWN 原因、普通修正后标题刷新且提示仍未公开、旧精选意图保留但不声称入选。另使用 Ego Lite 检查公开、索引和强制精选拒绝及普通修正反馈，没有写入真实内容。
