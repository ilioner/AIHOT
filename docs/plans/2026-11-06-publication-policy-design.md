# 分析通过后自动公开

使用者确认取消内部隔离，且以最新要求覆盖此前 UNKNOWN 放行约定：预筛 UNKNOWN 与 BLOCK 都是不通过，只有 PASS 继续通用模型分析。

## 实施

1. 预筛保留原始标签；UNKNOWN 停止后续评分、分类和写作，归一化为 block。所有公开出口继续使用统一发布层，要求当前版本存在成功的通过分析，未分析、失败、被拦截和人工下架保持不可见。
2. 删除内部隔离参与方式、目录采集限制和后台文案。保留 editorial 与 hot_signal；公开不等于精选，精选仍需评分与归组。全文许可开关不变，教程默认只展示摘要和原文链接。
3. 新迁移增加仅允许两种参与方式的 NOT VALID 约束，并删除历史约束。独立修复脚本先预览、逐来源转换和审计、处理历史 UNKNOWN，再逐条重建发布投影，最后验证约束；不删除原始材料、模型输出或回执，不重新调用模型。
4. 验证 UNKNOWN 阻断、历史 UNKNOWN 不泄漏、当前通过分析自动公开、过期/失败分析不公开、人工下架不恢复，以及目录采集和所有公开出口。

不新增开关、环境变量或付费请求，不执行 Git 提交。
