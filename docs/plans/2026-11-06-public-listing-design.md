# 信息流、PDF 通知与采集元信息展示

使用者确认：没有来源日期时标记本站收录日期；PDF 政策只采集文件名称，不解析正文；BLOCK 与 unknown 都不要展示；已有封面、源站分类、标签、图标和对应链接需要展示在用户端。

## 规则

- 统一公开读取层只让 editorial、当前分析通过、标题非空的条目进入信息流。`unknown` 与 BLOCK 都不公开，待分析、失败和人工撤回保持不可见；摘要和来源日期不再是入池前提。仅热度信源与已有全文权限继续生效。最新规则见 [分析通过后自动公开](2026-11-06-publication-policy-design.md)。
- 缺失或不可采用的来源日期保留为空，信息流按稳定的首次收录时间排列，界面标注“收录”。重抓不刷新首次收录时间，不伪造源站发布日期。精选仍要求原有摘要／原帖、日期和评分条件，不能借放宽信息流规则入选。
- 网页通知通过既有 detail 规则读取完整标题，并识别 PDF 嵌入链接；PDF 直链只保留列表名称和链接。不会下载、OCR 或解析 PDF。仅名称的 PDF 经原有回执和预算做相关性预筛、分类，不评分、不写摘要、不推断正文事实。unknown 不入池。
- 网站卡片和详情从 publication 读取层获取经过 URL 校验的 sourceMetadata、图片和来源图标。源站分类／标签与本站分类／标签分开标注。保留原文、来源栏目、上游原文、PDF 链接；没有的字段不编造。

## 验收

既有测试文件覆盖：无摘要／无日期的 pass 信息流、unknown 与 BLOCK 排除、精选资格不扩大、重复采集时间稳定、PDF 不下载且完整名称保留、元信息到达用户端接口，以及既有全文许可限制。运行所有模块测试、类型检查、网页构建与测试、smoke，并使用 Ego Lite 检查电脑和手机页面。

本机存量通过原采集与发布接口重建；人工执行保留审计。不修改历史迁移，不提交 Git。
