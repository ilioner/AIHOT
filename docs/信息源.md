自动调度每 15 分钟检查到期信源，目录和教程每 24 小时、优设每 6 小时读取一次。仅在已有采集安全阀开启时运行；失败记录健康状态并等待下一周期。手动接入脚本不修改安全阀，但会提交处理队列，已启用的 worker 会按原预算继续处理。

已有部署可运行以下命令（先预览，再按需应用和抓取）：

```bash
node --env-file=.env modules/source-catalogs/scripts/sync.ts
node --env-file=.env modules/source-catalogs/scripts/sync.ts --apply
node --env-file=.env modules/source-catalogs/scripts/sync.ts --apply --collect
```

脚本只补缺失信源及类别，不覆盖已有管理员配置。首次接入覆盖当前入口返回的条目，不承诺穷尽平台历史。适配细节及已知边界见 [模块说明](../modules/source-catalogs/README.md)。
